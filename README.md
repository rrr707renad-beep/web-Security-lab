Web Security Lab
A simple web security lab built using Python, Flask, and SQLite.
Project Overview
This project demonstrates basic web application security concepts through a simple login system.
The lab includes password hashing, secure database queries, and basic input validation.
Security Features
Password hashing using Werkzeug
Parameterized SQL queries to prevent SQL Injection
Basic input validation
Username length restriction
Secure login verification

Flask
SQLite
HTML

Skills Demonstrated
Web application security

Purpose
This project was created for learning and practicing basic web security concepts in a local environment.
